自然语言输入 · 42 words

Design a landing page for Pulse, an AI project status tool for remote creative teams. Show how it connects project tools, creates a daily brief, and spots blockers before stand-up. Include features, a testimonial, pricing, and a free-trial CTA.

[Requirements] hierarchy, interaction states, desktop/tablet responsiveness
A · 仅自然语言模型自行补全设计决策
B · 设计起点 Prompt构图与结构已经明确

结果对比

01 · 页面轮廓默认模板 vs 明确节奏

自然语言版落入常见的居中 Hero + 三卡片结构；设计起点版形成可辨识的网格轮廓。

02 · 信息层级内容齐全 vs 阅读路径清楚

两版都有核心内容，但结构化 Prompt 对模块数量和顺序做了约束，扫读更稳定。

03 · 一致性局部好看 vs 系统统一

设计起点版的边框、间距、按钮和模块关系共享同一套规则，风格漂移更少。

04 · 可控性依赖运气 vs 可复现

自然语言结果更依赖模型默认偏好；结构化 Prompt 更容易复用、修改和交付。
